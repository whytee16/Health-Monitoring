# Внутренний климат / Inner Climate

Визуальный инструмент, с которым астронавт сам оценивает своё состояние в длительной миссии и получает понятные рекомендации. Состояние тела и психики показано как погода за окном базы.

Учебный прототип для хакатона. Не медицинское изделие и не продукт NASA: эмблема и название агентства не используются, только источники.

## Запуск

Откройте `index.html` (монитор астронавта) или `crew.html` (сайт экипажа) двойным кликом. Сервер, сеть и установка не нужны. Папки `models/` (3D-модели тела) и `audio/` (музыка) должны лежать рядом с этими файлами. Данные хранятся в браузере (localStorage и IndexedDB).

## Сайт экипажа «Орбита» (`crew.html`)

Отдельный сайт для всего экипажа, тоже открывается двойным кликом.

- Главная: 3D-ракета, психологический климат экипажа, кто допущен к работе, лидеры рейтинга.
- Кнопка «Персонал»: список сотрудников с поиском и фильтром по допуску. По клику открывается профиль.
- Обязательные чекапы: ОАК каждую пятницу, показатели с приборов каждое утро, самочувствие с картой боли в понедельник и четверг, психолог по средам, биохимия раз в 2 недели, денситометрия раз в месяц. Пропуск чекапа даёт недопуск к работе, пока результат не внесён.
- Психика (главный показатель): индекс из 8 шкал, динамика, выводы, советы, психолог, дыхательная практика. Индекс ниже 45 даёт недопуск до беседы с психологом.
- 3D-тело персонажа: кости, мышцы, вены и артерии, органы. Проблемные участки красные, пограничные оранжевые. Для костей есть график плотности и T-критерий по участкам, для мышц сила групп и упражнения, для сосудов давление и вероятность тромба по факторам.
- Питание: калории и БЖУ по формуле Миффлина — Сан Жеора с поправками по анализам.
- Тренировки: план на день по силе мышц, плотности костей, риску тромбоза и карте боли.
- Игровая часть: очки, уровни, характеристики персонажа, значки, рейтинг. Кнопка «+1 день» внизу страницы показывает, как просрочка чекапа приводит к недопуску.

## Сборка и проверка

```bash
python3 build.py              # src/* -> index.html
python3 tests/functional.py   # сквозная проверка в Chrome (нужен playwright)
python3 tests/balance.py      # баланс «Ковчега» на четырёх стратегиях
python3 tests/avatar.py       # модуль 09: карта целей и 3D-тело (WebGL)
python3 tests/crew.py         # сайт экипажа: допуск, психика, формы, 3D
```

## Дизайн и звук

Стиль Futuristic Space Wellness: стеклянные карточки, звёздный фон, шрифт Manrope (SIL OFL, встроен в страницу), общая тема `src/theme.css` для обоих сайтов.

Плеер Space Soundscape (`src/player.js`) есть на всех страницах: 5 категорий (Deep Space, Relax & Sleep, Focus Mode, Earth Memories, Cosmic Meditation), волны, громкость, свои треки, мягкие звуки интерфейса и гул корабля, кнопка «без звука». Музыка включается только по нажатию. Авторы встроенных треков в `audio/CREDITS.md`.

## 3D-модели тела

Модели в `models/` взяты из npm-пакета [open-anatomy-3d](https://www.npmjs.com/package/open-anatomy-3d) 0.1.0: мужское и женское тело, 128 и более структур отдельными мешами. Источники: BodyParts3D © DBCLS (CC BY 4.0), HuBMAP Human Reference Atlas (CC BY 4.0), MakeHuman (CC0). Подробности в `models/ATTRIBUTION.md` и `models/LICENSE-MODELS.md`; строка авторства показана под каждой 3D-моделью.

Изменения при загрузке (`src/atlas.js`): свои материалы и цвета, удаление повреждённых вытянутых треугольников у органов и сосудов, полупрозрачная оболочка лёгких поверх бронхиального дерева (в исходной модели лёгкое представлено только деревом бронхов). Если модель не загрузилась, показывается упрощённая фигура из `src/anat3d.js`.

## Числа и источники

Личные коридоры и дозы для дальних миров иллюстративные. Опорные значения:

- потеря плотности костей 1–1,5 % в месяц: [NASA, Risk of Spaceflight-Induced Bone Changes](https://www.nasa.gov/reference/risk-of-spaceflight-induced-bone-changes/)
- предел дозы за карьеру 600 мЗв: [NASA-STD-3001, технический обзор по радиации](https://www.nasa.gov/wp-content/uploads/2023/03/radiation-protection-technical-brief-ochmo.pdf)
- 1,8 мЗв/сут в перелёте и 0,67 мЗв/сут на поверхности Марса: [данные прибора RAD, SwRI](https://www.sciencedaily.com/releases/2013/12/131209181133.htm)
- пять опасностей полёта: [NASA Human Research Program](https://www.nasa.gov/hrp/hazards/)
